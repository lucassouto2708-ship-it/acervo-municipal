01Primeiro acesso

O administrador tem acesso total: envia documentos, cria clientes, libera acesso e cadastra qualquer usuário.

  1. Abra lucassouto2708-ship-it.github.io/acervo-municipal no navegador (Chrome ou Edge, no computador).
  2. Digite seu E-mail e Senha e clique em Entrar.
  3. Se você recebeu uma senha provisória (conta criada por outro administrador), o sistema pede para criar a sua: pelo menos 8 caracteres, digitada duas vezes. A provisória deixa de valer.
  4. Você cai na tela Acervo. Seu nome e o papel "Administrador" aparecem no canto superior direito.
Não existe "criar conta" na tela de entrada.O cadastro público está desligado de propósito. Toda conta nasce pelas mãos de um administrador (ou de um cliente, no caso de leitores).
Para sairUse o botão no canto superior direito (seta para fora). Em computador compartilhado, sempre saia ao terminar.

04Enviar documentos

  1. Abra Enviar.
  2. Arraste os PDFs ou a pasta inteira para a área tracejada, ou use Escolher arquivos / Escolher pasta.
  3. Confira a tabela. O sistema preenche sozinho o que conseguir ler do caminho do arquivo: entidade, tipo, mês e ano. Por exemplo, IPREMA/Movimento Contabil 012026.pdf vira "Movimento contábil · Janeiro/2026" do IPREMA.
  4. Complete o que faltar. Linhas incompletas aparecem com "Falta: …" em vermelho e o botão de envio fica bloqueado.
  5. Preencha a Descrição / palavras-chave (opcional, veja abaixo).
  6. Clique em Enviar N arquivos.

Descrição / palavras-chave

Texto livre que entra na busca junto com o texto do PDF. Use para termos que não aparecem escritos no documento ou para facilitar achar: "folha de pagamento, precatórios, prestação de contas TCE".

  • Cada arquivo tem o seu campo na tabela.
  • Descrição para todos, no topo: digite e tecle Enter para aplicar a todos os arquivos da lista.
  • Dá para incluir ou mudar depois, em Documentos → editar.

Processamento

Depois do envio, cada PDF é lido página por página (texto para a busca e miniatura de cada página). O andamento aparece no quadro Processamento: Na fila → Processando (página X de Y) → Pronto.

Mantenha o sistema aberto até terminarO processamento acontece no seu navegador. Pode trocar de tela dentro do sistema ou de aba, mas não feche a janela. Se fechar, ao abrir de novo no mesmo computador ele continua de onde parou.
Arquivos grandes são comprimidos sozinhosO limite atual é 50 MB por arquivo. Acima disso, o sistema reduz só as imagens das páginas até caber; o texto e a busca continuam iguais. O documento mostra uma observação com o tamanho antes e depois.

Arquivo repetido: se o mesmo PDF já existir no acervo, o envio para com "Arquivo idêntico a …" e nada é duplicado.

05Clientes e liberação de acesso

Cada cliente é uma organização (prefeitura, instituto, escritório). Os usuários de um cliente só enxergam o que for liberado para ele.

Criar um cliente

  1. Clientes → Novo cliente.
  2. Informe o nome (e o CNPJ, se quiser). Pode já criar o primeiro usuário dele: nome e e-mail.
  3. Clique em Criar cliente. Se criou usuário, aparece a senha provisória para você repassar.

Liberar documentos

Na página do cliente, quadro O que este cliente vê → Liberar mais:

LiberarO cliente passa a ver
Entidade inteiraTodos os documentos daquele órgão (ex.: tudo do IPREMA).
Município inteiroTodos os documentos de todas as entidades do município.
CaixaSó os documentos daquela caixa.
Documento avulsoSó aquele documento.

Em Tipos de documento você pode restringir: por exemplo, liberar o município inteiro mas só Leis.

Documentos novos entram sozinhosSe você liberou uma entidade, todo documento novo dessa entidade aparece para o cliente assim que ficar "Pronto". Não precisa liberar de novo.
  • Revogar tira o acesso na hora.
  • Suspender bloqueia todos os usuários daquele cliente até você reativar.

Cadastrar alguém que só consulta e baixa

  1. Clientes → abra o cliente → quadro Usuários → Novo usuário.
  2. Nome, e-mail e papel Leitor (ou Cliente, se a pessoa também for cadastrar leitores).
  3. Clique em Criar acesso. Aparece a senha provisória (ex.: acervo-4821-kmpt).
  4. Clique em Copiar acesso e envie para a pessoa junto com o endereço do sistema.
A senha provisória aparece uma vez sóCopie antes de fechar. Se perder, gere outra com Senha na linha do usuário.

Outras ações

  • Senha gera nova senha provisória (para quem esqueceu). A antiga para de funcionar.
  • Desativar corta o acesso na hora, sem apagar o histórico. Reativar devolve.
  • Novos administradores: menu Administradores → Novo administrador.

07Pesquisar, abrir, baixar e imprimir

Pesquisar

  • Digite palavras no campo de busca do Acervo. O sistema procura no texto de todas as páginas e na descrição, sem diferenciar acento ou maiúscula, e acha singular e plural ("dotação" acha "dotações").
  • Filtros à esquerda: município, entidade, tipo, caixa e ano. O número ao lado (ex.: 2026 · 7 docs) mostra quantos documentos ficam se você clicar.
  • Com várias palavras, todas precisam estar na mesma página ou na descrição.

Abrir

  • Clique num documento: abre um painel com capa, dados, Buscar neste documento e as páginas onde o termo aparece, com o trecho destacado.
  • Clique numa página ou em Abrir para ver o documento com o termo marcado em cima da página. Use ← e → para trocar de página e as setas ↑↓ para pular entre páginas com o termo.

Baixar e imprimir só as páginas que precisa

Baixar PDF e Imprimir abrem uma escolha: Documento inteiro, Página atual, Páginas com o termo pesquisado ou Escolher páginas (digite 1-3, 7, 10-12 ou clique nas miniaturas). O sistema monta um PDF só com elas, com o texto pesquisável.

08Gerenciar documentos

Em Documentos, cada linha tem:

  • Abrir: visualizar.
  • Editar (lápis): título, município, entidade, tipo, caixa, mês, ano, número do ato e descrição.
  • Reprocessar (seta circular): aparece quando houve erro; lê o PDF de novo.
  • Remover (lixeira): apaga o PDF, o texto e as miniaturas. Não dá para desfazer.

Situações: Pronto, Processando, Na fila, Erro (motivo aparece embaixo do título) e Sem texto (PDF sem texto reconhecível: aparece no acervo, mas a busca por palavras não acha nada nele).

09Auditoria

Tudo fica registrado: quem entrou, o que pesquisou, que documento abriu, baixou ou imprimiu (e quais páginas), e toda alteração em documentos, acessos e usuários. Filtre por pessoa, ação ou texto. Ninguém além dos administradores vê a auditoria, e ninguém consegue apagar registros.

10Boas práticas e limites

  • Repasse senhas provisórias por um canal direto com a pessoa (WhatsApp, ligação), nunca em grupo.
  • Desative quem saiu da equipe de um cliente no mesmo dia.
  • Libere por entidade ou município sempre que possível: é mais simples de manter que documentos avulsos.
  • Saia do sistema em computadores compartilhados.
Plano atual (versão de demonstração)Armazenamento total de 1 GB e até 50 MB por arquivo (acima disso o sistema comprime). O projeto pausa se ficar 7 dias sem uso; reative pelo painel do Supabase. A versão definitiva terá espaço para o acervo completo.
