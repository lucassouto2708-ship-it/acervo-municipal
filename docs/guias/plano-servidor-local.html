03Parte 1 · você faz (~40 min)

1. BIOS

  1. Reinicie e entre na BIOS (Del, F2 ou F10 ao ligar).
  2. Restore on AC Power Loss (ou "AC Back", "Power On After Power Failure") → Power On. O PC liga sozinho quando a luz volta.
  3. Confirme a virtualização ativada: "Intel VT-x" ou "SVM Mode" (AMD). Salve e saia.

2. Windows: nunca dormir

  1. Configurações → Sistema → Energia: tela e suspensão Nunca (na tomada).
  2. Windows Update → Opções avançadas → Horário ativo 6h–23h, para reinícios caírem de madrugada.

3. Windows: entrar sozinho

  1. Se você entra com PIN ou Windows Hello: Configurações → Contas → Opções de entrada → desative "Exigir entrada com o Windows Hello".
  2. Baixe o Autologon da Microsoft (Sysinternals): learn.microsoft.com/sysinternals/downloads/autologon.
  3. Digite sua senha do Windows e clique em Enable.
Só você mexe nissoNão passe sua senha do Windows para ninguém, nem para mim. Com login automático, quem tiver acesso físico ao PC entra nele: deixe o PC em local fechado.

4. WSL e Docker Desktop

  1. PowerShell como administrador: wsl --install. Reinicie.
  2. Instale o Docker Desktop: docker.com/products/docker-desktop.
  3. Settings → General: marque Start Docker Desktop when you sign in.
  4. Antes de qualquer outra coisa: Settings → Resources → Advanced → Disk image location → escolha uma pasta no HD do acervo (ex.: D:\Docker). Apply.
Por que o passo 4 é importanteO Docker guarda tudo num disco virtual que, por padrão, fica no C: e cresce sem limite. Mudando o local antes, banco e PDFs ficam no HD grande e o C: não lota.

5. Domínio e Cloudflare

  1. Crie a conta em dash.cloudflare.com.
  2. .com: compre direto no Cloudflare (Domain Registration). Já fica pronto.
  3. .com.br: compre no registro.br, adicione o domínio no Cloudflare e troque os servidores DNS no registro.br pelos dois que o Cloudflare mostrar. Propaga em minutos a algumas horas.
Pronto?Com o Docker abrindo sozinho e o domínio "Active" no Cloudflare, me chame para a Parte 2.

05Parte 3 · depois

  • 1 semana de segurança: o Supabase da nuvem fica congelado como cópia, sem receber nada novo. Se algo der errado, eu volto o site para ele; o que foi enviado nesse meio tempo precisaria ser reenviado.
  • Tudo certo: desligue o projeto no Supabase da nuvem.
  • Uma vez por mês: confira a data do último backup e se ainda há espaço nos dois HDs.

08Limites e cuidados

  • Upload até 100 MB pelo Cloudflare grátis. O compressor do app já reduz tudo acima de 50 MB, então não deve aparecer.
  • Velocidade de download dos usuários depende do upload da internet deste local.
  • Sem luz ou internet no local, o sistema fica fora do ar até voltar.
  • Backup só vale se ficar fora do HD do acervo. Idealmente, leve uma cópia para outro lugar de vez em quando (roubo, incêndio).
  • Docker Desktop é grátis para uso pessoal e empresas pequenas (menos de 250 funcionários e menos de US$ 10 milhões por ano).
